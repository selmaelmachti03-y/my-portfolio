# My Developer Portfolio

A responsive personal portfolio website for a student exploring Artificial Intelligence, Data Science, and Web Development.

## Features
- Responsive layout for desktop, tablet, and mobile
- About, skills, projects, and contact sections
- Light/dark mode toggle
- Built with plain HTML, CSS, and JavaScript

## Run locally
1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Optional: open the folder in Visual Studio Code and use the Live Server extension.

## Customise it
- Replace `Salma` with the name you want to display.
- Update the About and Skills sections to reflect your real experience.
- Replace the GitHub profile link in `index.html` with your profile URL.
- Add links to your real projects as you create them.

## Project files
- `index.html` — page structure and content
- `style.css` — design, responsive layout, and dark mode styles
- `script.js` — theme toggle and current year
